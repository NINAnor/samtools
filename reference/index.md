# Package index

## All functions

- [`create_odmap()`](https://ninanor.github.io/samtools/reference/create_odmap.md)
  : Create folder with ODMAP structure
- [`data_prep_rsf_habitat_rein()`](https://ninanor.github.io/samtools/reference/data_prep_rsf_habitat_rein.md)
  : Prepare data for RSF analyses for wild and semi-domesticated
  reindeer within SAM
- [`data_prep_ssf_movement_rein()`](https://ninanor.github.io/samtools/reference/data_prep_ssf_movement_rein.md)
  : Prepare data for SSF movement/permeability analyses for wild and
  semi-domesticated reindeer within SAM
- [`db_make_query()`](https://ninanor.github.io/samtools/reference/db_make_query.md)
  : Helper function to prepare queries to be sent to PostgreSQL
- [`db_read_vect()`](https://ninanor.github.io/samtools/reference/db_read_vect.md)
  : Helper function to read vector layers from PostGIS database
- [`db_summarize()`](https://ninanor.github.io/samtools/reference/db_summarize.md)
  : Summarize number, length, and area of features per area/region
- [`db_write_vect()`](https://ninanor.github.io/samtools/reference/db_write_vect.md)
  : Helper function to upload vector layers to PostGIS database
- [`extract_along()`](https://ninanor.github.io/samtools/reference/extract_along.md)
  : Extract values of raster using in parallel
- [`grass_get_res()`](https://ninanor.github.io/samtools/reference/grass_get_res.md)
  : Get resolution from a raster map in a GRASS GIS database
- [`grass_raster_info()`](https://ninanor.github.io/samtools/reference/grass_raster_info.md)
  : Get information from a raster
- [`grass_set_region()`](https://ninanor.github.io/samtools/reference/grass_set_region.md)
  : Set the region in a GRASS GIS session
